# CabinOps crew console

React portal for flight settings, request acceptance/completion, galley inventory, announcements, and cabin seat inspection.

```bash
npm ci
npm run dev
npm run build
```

Development runs at http://127.0.0.1:5174 with `/api` proxied to the backend on port 8000. Set `VITE_BACKEND_PORT` for another local API port. See the [root README](../../README.md) for authentication and container deployment.
